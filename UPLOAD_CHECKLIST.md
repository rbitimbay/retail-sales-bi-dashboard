# GitHub Upload Checklist

1. Create a new public repository named `retail-sales-bi-dashboard`.
2. Upload the contents of this folder, not the outer folder itself.
3. Keep `README.md` at the repository root so GitHub renders it automatically.
4. Add a short repository description:
   `Interactive Power BI retail sales dashboard with DAX, decomposition tree, market basket analysis, and geographic insights.`
5. Suggested GitHub topics:
   `power-bi`, `dax`, `business-intelligence`, `data-analysis`, `data-visualization`, `portfolio-project`
6. Add the GitHub repository link to the Projects section of your resume.
7. Add the same link to LinkedIn → Projects and LinkedIn → Featured.
8. If you later find the exact original GitHub dataset URL, add it to the Dataset section of README.md.
